## PAGE SETUP & FORMATTING (DO NOT CHANGE FOR ANY REASON)

US Letter (12240 × 15840 DXA), margins: top/bottom 648, left/right 864.

Font: Calibri throughout. Color palette:
- `NAVY = "1B3A6B"` — name, section headers, company names
- `BLUE = "1A6EB5"` — contact links
- `DARK = "1A1A1A"` — bold keywords in bullets
- `BODY = "333333"` — regular body text
- `GRAY = "777777"` — subtitle, contact separators, dates, italic lines

## DIVIDERS

Two dividers are used — one after the header, one between summary and competencies. Use independent spacing for each:

```js
function divider(before = 30, after = 30) {
  return new Paragraph({
    border: { bottom: { style: BorderStyle.SINGLE, size: 10, space: 1, color: NAVY } },
    spacing: { before, after },
    children: []
  });
}
```

- **After header:** `divider()` — default `before: 30, after: 30`
- **Between summary and competencies:** `divider(10, 10)` — tighter, less vertical gap

## JOB HEADERS

Single paragraph, right tab stop at position 9360. Company bold navy size 18 + role body size 17. Date/location italic gray size 16 right-aligned. Spacing `before: 55`.

```js
function jobHeader(company, role, dateLocation) {
  return new Paragraph({
    tabStops: [{ type: TabStopType.RIGHT, position: 9360 }],
    spacing: { before: 55, after: 0 },
    children: [
      new TextRun({ text: company, font: "Calibri", bold: true, color: NAVY, size: 18 }),
      new TextRun({ text: "  " + role, font: "Calibri", color: BODY, size: 17 }),
      new TextRun({ text: "\t" + dateLocation, font: "Calibri", color: GRAY, size: 16, italics: true }),
    ]
  });
}
```

## BULLETS

`LevelFormat.BULLET` with `"•"`, indent `left: 360, hanging: 220`, spacing `before: 18`, size 17. Bold keywords `color: DARK`, regular text `color: BODY`.

```js
numbering: {
  config: [{
    reference: "bullets",
    levels: [{
      level: 0, format: LevelFormat.BULLET, text: "•",
      alignment: AlignmentType.LEFT,
      style: { paragraph: { indent: { left: 360, hanging: 220 }, spacing: { before: 20, after: 0 } } }
    }]
  }]
}

function bullet(runs) {
  return new Paragraph({
    numbering: { reference: "bullets", level: 0 },
    spacing: { before: 18, after: 0 },
    children: runs
  });
}
// Bold:   new TextRun({ text, font: "Calibri", bold: true, color: "1A1A1A", size: 17 })
// Normal: new TextRun({ text, font: "Calibri", color: "333333", size: 17 })
```

## CONTENT OPTIMIZATION RULES (ATS + JD ALIGNMENT)

**1. Years of experience:**
Always write **"5+ years"** hardcoded in both the summary paragraph and the tagline if experience is mentioned. Never calculate from employment dates. Never write "4+ years" or any other value.

**2. Keyword gap-filling:**
Identify every required skill, tool, methodology, and keyword from the JD. For any keyword missing from the resume, extrapolate naturally into existing bullets using context from the candidate's actual experience — do not fabricate roles or companies, only enrich existing bullets with plausible technical detail.

**3. Tagline & summary:**
Rewrite the subtitle tagline and summary paragraph to mirror the exact language and priorities of the JD. Lead with the most relevant credential for that specific role.

**4. Bullet rewriting:**
Rewrite bullets to front-load action verbs preferred in the JD. Weave in JD keywords naturally. Preserve all metrics (50K+ queries, 40% reduction, etc.) — never remove a number.

**5. Required bullets — always include these for every resume:**
- **Design system bullet** (AWI): "Built and maintained a shared component design system across React web and React Native mobile — standardizing tokens, typography, and interaction patterns."
- **Testing bullet** (AWI): "Wrote Jest and React Testing Library unit and integration tests for chatbot UI and CMS workflows, enforcing testable code standards and catching regressions pre-deploy."
- **Collaboration bullet** (AWI): "Collaborated with ML researchers, product managers, and UX designers to translate GraphRAG model outputs into intuitive conversational UI flows."
- These three bullets must always appear in the AWI section regardless of the JD.

**6. Competencies reordering:**
Reorder the competency rows so the most JD-relevant category appears first. Add any missing tools from the JD into the appropriate row.

**7. Location:**
Always use `Tempe, AZ (Open to Relocate)` — never substitute the job posting's city.

**8. ATS bolding rule:**
Bold all tech tools, metrics, action verbs, and proper nouns inline within bullets using `TextRun` — never use markdown or unicode formatting.

3. Reduce spacing: job headers `before: 55 → 45`, bullets `before: 18 → 14`
4. Reduce section header spacing: `before: 55 → 45`
5. Reduce divider spacing
6. As last resort only: reduce body text size from 17 → 16 (competencies and bullets only — never touch name, tagline, or section headers)

**Never remove:** metrics, award lines, the hackathon win, the published research bullet, or the three required AWI bullets (design system, testing, collaboration).
